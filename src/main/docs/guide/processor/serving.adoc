To expose the generated JSON Schema output from your running application, add https://docs.micronaut.io/latest/guide/#staticResources[static resources] configuration.

[configuration]
----
micronaut:
  router:
    static-resources:
      jsonschema:
        paths: classpath:META-INF/schemas
        mapping: /schemas/**
  jsonschema:
    validation:
      baseUri: https://example.com/schemas
----

<1> The schemas are exposed on the `/schemas` path, which can be customized for your specific needs.
<2> The schemas are be read from the `META-INF/schemas` classpath folder.

When you serve the schemas, set the `micronaut.jsonschema.baseUri` annotation processor option (see <<globalConfiguration, JSON Schema Configuration>>) to the URL they are served at, for example `https://example.com/schemas`, so that the `$id` and the `$ref`s of the served schemas point to that URL instead of the classpath, and set `micronaut.jsonschema.validation.baseUri` to the same URL so that api:jsonschema.validation.JsonSchemaValidator[] still resolves the references from the classpath.
