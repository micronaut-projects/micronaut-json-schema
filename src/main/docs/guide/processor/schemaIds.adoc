Each generated schema has an `$id` made of the base URI and the schema's URI. Unless the `uri` member of the api:jsonschema.JsonSchema[] annotation is set, the URI is the kebab case of the title, which defaults to the simple name of the class. The simple name of a nested class includes the classes it is nested in, so the schema of `Order.Line` is `/order-line.schema.json`, and the schema of a class annotated with `@JsonSchema(title = "RedWingedBlackbird")` is `/red-winged-blackbird.schema.json`. The schema is written to the same path under `META-INF/<outputLocation>/`, where api:jsonschema.utils.JsonSchemaClassPathResourceLoader[] and api:jsonschema.validation.JsonSchemaValidator[] find the schema of a class.

A property whose type is another `@JsonSchema` type references that schema with a `$ref` to its `$id`.

By default, the base URI is `classpath:META-INF/<outputLocation>` (`classpath:META-INF/schemas` unless `micronaut.jsonschema.outputLocation` is set), which is where the schema files are written. JSON Schema validators that resolve `classpath:` URIs, such as https://github.com/networknt/json-schema-validator[NetworkNT JSON Schema Validator] (used by api:jsonschema.validation.JsonSchemaValidator[] and by Apache Camel's JSON Validator component), therefore resolve the references between generated schemas from the classpath without any configuration and without network access.

Set `micronaut.jsonschema.baseUri` when the schemas are published at a URL, for example when you <<serving, serve them from your application>>, so that the `$id` and the `$ref`s point to that URL.

NOTE: Before Micronaut JSON Schema 2.3.2, the default base URI was `http://localhost:8080/schemas`, which made validators fetch referenced schemas over HTTP. To keep the previous IDs, set the `micronaut.jsonschema.baseUri` annotation processor option to `http://localhost:8080/schemas`. api:jsonschema.validation.JsonSchemaValidator[] still maps `http://localhost:8080/schemas/` (configurable with `micronaut.jsonschema.validation.base-uri`) to the classpath, so schemas generated by earlier versions keep validating.
